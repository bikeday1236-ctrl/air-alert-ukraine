# Air Alert Ukraine

Сервер на Node.js збирає статуси повітряних тривог, зберігає історію в SQLite і віддає їх PWA-фронтенду (Leaflet) через SSE.

## Запуск
1. Отримай безкоштовний токен API на alerts.in.ua.
2. `npm install`
3. `ALERTS_TOKEN=твій_токен npm start` (Windows PowerShell: `$env:ALERTS_TOKEN="..."; npm start`)
4. Відкрий http://localhost:3000

## Межі областей
Сервер при першому запуску намагається завантажити GeoJSON (`GEOJSON_URL`) у `data/oblasts.geojson`.
Якщо не вийшло, поклади туди власний файл меж областей України (назви областей українською). У консолі буде видно, яке поле назви знайдено.

## Налаштування (змінні середовища)
`PORT`, `POLL_MS` (30000), `STALE_MS` (120000), `GEOJSON_URL`.

## Правила достовірності
- Якщо джерело мовчить довше за `STALE_MS`, усі області стають жовтими («потребує перевірки»).
- Окремо показано час публікації та час отримання.
- Час відбою = момент, коли область зникла зі списку активних (джерело інакше його не віддає).
- Дублі відсікає унікальний індекс в історії.

## Обмеження
- Push, коли сайт закрито, потребує VAPID-ключів і окремого сервісу. Зараз звук і сповіщення працюють, поки вкладка або PWA відкриті.
- Для встановлення PWA на телефон потрібен HTTPS.
- Цілі типу «шахед/ракета» не додані: надійного відкритого офіційного API для них немає.
